# 扫描确认与收录文件类型

最后验证日期：2026-11-05。

新建索引库首次打开时，先显示“确认扫描范围”。界面创建只查询系统常用目录配置，不枚举磁盘、不登记目录、不扫描文件。旧库沿用已有范围，不强制弹出引导。

- 常用资料目录（桌面／文档／下载）在存在时默认勾选，仍需点击“开始扫描”。发现的整块磁盘保持不勾选，避免误触发全盘扫描。
- “发现本地磁盘”仅发现候选；发现完成后仍需勾选并确认开始。整盘扫描较慢，建议优先只选常用目录或具体项目文件夹。
- 空库首次扫描采用渐进发布：每完成一批即写入索引并可立即搜索，不必等整卷扫完；重扫仍保持整根原子快照，扫描期间读旧快照。取消首扫保留已扫描到的部分。
- 默认勾选办公文档，只建立文件名索引，不启用正文、OCR 或语义处理。可增加图片、音视频、压缩包、代码文本类别及自定义后缀，或明确选择全部类型。
- 文件类别限制仍会遍历所选目录。缩小目录范围才能减少遍历量；选择办公文档不表示跳过其他目录。
- 扫描仍核验目录和对象身份。对不收录的文件，在身份与路径编码检查后跳过创建时间查询及完整索引记录构造，减少无用处理；文件夹继续保留导航，不改变原文件。具体耗时收益以本轮同机实测为准。
- 取消确认界面不会登记范围，也不保存批准状态。已开始后的暂停、取消保留已发布索引；继续可接着处理剩余范围。

在“索引文件夹”选择目录后，点击“收录文件类型…”可修改该根策略。保存时先使普通搜索、快速定位和预览失效，再暂停扫描；服务收尾和写锁等待都在后台执行。成功后刷新查询并请求重新扫描，原先已暂停的服务保持暂停。保存失败保留暂停状态并显示原因。修订冲突需关闭后重新打开编辑器读取当前策略。

收窄策略会从索引移除不再符合条件的文件名条目，不删除实际文件。旧库没有显式策略的根继续使用全部类型，避免静默改变已有范围。多根首次设置逐根提交，遇到失败不会继续启动扫描；状态中列出已登记及已应用策略的范围，便于管理和重试。

验证范围：真实 PyQt5 界面与 D 工作区合成目录、注入候选。测试不执行本机磁盘发现或全盘扫描。原进度面板固定高度、200 ms 合并更新逻辑保留。
渐进发布与默认范围另有 `tests/test_progressive_scan.py`、`tests/test_first_run_scope.py`；拼音首字母见 `tests/test_pinyin.py`。

进度展示只报告可核验的真实量（已收录项数、实测速率、已完成范围数）。磁盘文件总数在扫描前未知，因此不显示编造的百分比或剩余时间。

本地验证命令：`.build/v017/venv/Scripts/python.exe -m unittest tests.test_scan_setup_ui tests.test_v017_bugfixes.ProgressPanelTests -v`。覆盖首次取消、显式发现、后缀策略、重叠范围、失败留痕、真实主窗口 writer 等待及固定进度面板。
