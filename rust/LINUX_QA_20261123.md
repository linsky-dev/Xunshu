# Xunshu 0.18.0-alpha.3 — 离线 Linux 编译与测试验收

验证日期：2026-11-23。环境：Debian 13 x86_64 / Rust 1.99.1 / Cargo 离线 Vendor。

## 结果

- `cargo check --workspace --offline`：通过（现有 unused 字段警告）。
- `cargo test --workspace --offline --no-fail-fast`：**192 通过，0 失败**，包含 Rust 工作区单元测试与集成测试；不代表桌面图形、安装器或跨平台验证。
- 首次运行时大多数测试因容器 OverlayFS 被安全策略拒绝；改用 `/dev/shm` 的真实 tmpfs 进行测试，**未关闭或放宽文件系统安全检查**。
- 修复拼音倒排测试与新版 FileRecord 接口不匹配的编译错误。
- 修复正文集成测试：支持显式指定安全挂载点内的 worker 可执行文件；超时测试强制修改文档以阻止增量复用绕过 worker；验证索引代际保持、修改过的旧结果被标记为 stale。
- `cargo fmt --all -- --check` 仍有格式差异，本轮未为消除样式差异而批量格式化原始文件。

## 复现

在安装 Linux Rust 1.99.1、配齐 Cargo Vendor 并确保真实 tmpfs `/dev/shm` 后：`bash rust/scripts/verify_offline_linux.sh`。若首次未构建 worker 可执行文件，请先执行 `cargo build -p xs-content --bin xs-content-worker --offline`。
